# RenProfile · Windows 用户文件夹改名

把 `C:\Users\旧用户名` 改成 `C:\Users\NewName`，保留原来的 Windows 账户、SID、登录密码和文件权限，并迁移相关路径设置。

**当前版本：4.1.0。双击使用，不需要安装 Python，也不需要输入命令。**

**[下载最新版](https://github.com/zhaibingye/RenProfile-Py/releases/latest)** · [直接下载 4.1.0 EXE](https://github.com/zhaibingye/RenProfile-Py/releases/download/v4.1.0/RenProfile-4.1.0.exe) · [反馈问题](https://github.com/zhaibingye/RenProfile-Py/issues)

## 先看这三件事

- 使用 Windows 10 / 11 的 x64 电脑（Intel / AMD 64 位），用户文件夹位于本地 NTFS 磁盘。其他系统和架构未验证。
- 需要登录**另一个管理员账户**操作。仅以管理员身份运行，不能代替注销要改名的用户。
- 本工具只改同一位置的文件夹名称，例如 `C:\Users\旧用户名 → C:\Users\NewName`；不搬到其他磁盘，也不支持只改大小写。

它的目标是尽量保留原有环境，但不能保证所有第三方软件完全不受影响。工具的恢复记录只备份本次改动，不是个人文件的完整备份；重要文件请另存一份。

## 第 1 步：下载并放好工具

1. 打开上面的 **下载最新版**。
2. 在页面下方的 **Assets（资源）**中，下载名称类似 `RenProfile-4.1.0.exe` 的文件。不要选 `Source code`，那是给开发者看的源码。
3. 在 C 盘新建一个 `RenProfile` 文件夹，把 EXE 放进去，例如 `C:\RenProfile\RenProfile-4.1.0.exe`。这样换一个账户后，也容易找到。

发布文件名始终带版本号。下载后通常无需解压、安装或联网运行。若 Windows 提示无法验证发布者，这是因为当前 EXE 没有代码签名；先核对下载来源，**不需要关闭杀毒软件或系统防护**。

## 第 2 步：准备另一个管理员账户

如果已经有另一个能登录的管理员账户，直接进入第 3 步。

<details>
<summary><strong>没有另一个管理员账户？点这里，跟着创建</strong></summary>

先在有管理员权限的账户中操作：

1. 打开 **开始 → 设置 → 账户 → 其他用户**。Windows 10 中可能叫 **家庭和其他用户**。
2. 点击 **添加账户**，或 **将其他人添加到这台电脑**。
3. 依次选择 **我没有这个人的登录信息 → 添加一个没有 Microsoft 账户的用户**。
4. 新用户名可以填写 `RenProfileAdmin`，设置一个自己记得的密码，完成创建。
5. 回到 **其他用户**，点击刚创建的 `RenProfileAdmin`，选择 **更改账户类型 → 管理员 → 确定**。

这个账户只是用来帮原账户改名。你最终仍然登录原来的账户。若电脑由单位管理、不能添加用户，请让管理员准备这个账户。

界面因 Windows 版本可能略有不同，可参考[微软的账户管理说明](https://support.microsoft.com/zh-cn/windows/security/identity-signin/manage-user-accounts-in-windows)。

</details>

## 第 3 步：重启，只登录另一个管理员

1. 保存正在编辑的文件。在原账户中按 **Win + R**，输入 `%USERPROFILE%` 并回车，查看资源管理器地址栏，记下原路径，例如 `C:\Users\旧用户名`。
2. **重启电脑。** 到登录画面后，只登录刚准备好的管理员，例如 `RenProfileAdmin`。
3. 接下来直到迁移完成，都不要登录要改名的原账户。

如果已经登录了原账户，按 **Ctrl + Alt + Delete → 注销**，再登录另一个管理员。锁屏、关闭窗口和“切换用户”都不等于注销。

## 第 4 步：打开工具，输入新名称

1. 打开 `C:\RenProfile`，双击 `RenProfile-4.1.0.exe`。
2. Windows 询问是否允许更改设备时，点击 **是**。如果程序短暂关闭后重新出现，属于正常启动过程。
3. 在 **选择要改名的用户**中，按后面显示的原文件夹路径选择，例如 `C:\Users\旧用户名`。
4. 在 **输入新的文件夹名称**中，只填写 `NewName`，不要填写 `C:\Users\NewName`。
5. 核对下方的 **将改为**，确认是自己想要的路径，点击 **开始改名**，等待结果。扫描可能需要一段时间，请不要强行关闭程序或同时再开一个工具。

新名称不能与已有文件夹重复。建议使用简短的英文字母或数字，例如 `NewName`、`Alex2026`。

**如果直接提示“迁移完成”，跳到第 6 步。只有出现手动改名窗口时，才需要第 5 步。**

## 第 5 步：自动改名受阻时，手动改名后继续

Windows 有时会阻止程序自动改名。工具会先恢复本次已记录的改动，再弹出 **手动改名后继续** 窗口。

1. 保持工具打开，点击 **打开所在文件夹**。
2. 按提示找到原文件夹。也可以在资源管理器的地址栏输入 `C:\Users`，按回车；请以工具实际显示的路径为准。
3. 选中原文件夹，按 **F2**，把名称改成工具窗口里的新名称，例如从 `旧用户名` 改成 `NewName`。出现管理员确认时，点击 **继续**。
4. 回到工具，点击 **我已改名，继续迁移**，等待 **迁移完成**。

这一步是在原位置直接重命名原文件夹，**不需要新建文件夹，也不需要复制或移动里面的文件**。如果同名文件夹已存在，不要合并或覆盖它。

<details>
<summary><strong>手动改名仍被拒绝，或者不小心关闭了工具</strong></summary>

- **手动也提示拒绝访问 / 正在使用：** 点击 **稍后处理**，重启后只登录维护用的管理员。重新打开工具，选择相同的原用户、填写相同的新名称，再尝试。若资源管理器依然无法改名，记录提示并[反馈问题](https://github.com/zhaibingye/RenProfile-Py/issues)，不要强行修改用户文件夹权限。
- **已经手动改好，工具却关了：** 保持原用户注销，重新打开工具，选择原用户、填写相同的新名称，点击 **开始改名**。软件会识别已改名的文件夹，核对后继续迁移设置。
- **点继续时提示还没改好：** 对照窗口里的两个完整路径，检查是否改错文件夹、拼写不同，或只新建了一个同名文件夹。确认原文件夹实际改名后，再点继续。

**手动改名后，即使文件夹名称已经变了，也要等工具完成设置迁移，再登录原用户。**

</details>

## 第 6 步：完成后重启，登录原账户

1. 工具显示 **迁移完成** 后，关闭工具并重启电脑。
2. 登录**原来的账户**，使用原来的密码或 PIN，不是维护用的 `RenProfileAdmin`。
3. 看看桌面、文档和常用软件是否正常。
4. 想确认新路径时，按 **Win + R**，输入 `%USERPROFILE%`，按回车；在资源管理器地址栏查看是否为新路径。

登录画面的账户显示名称可能保持原样，这是正常的：本工具修改的是磁盘上的用户文件夹名称。

**旧名称仍然出现也正常，请保留它。** 它是指向新文件夹的兼容入口，方便仍使用旧路径的软件访问同一份文件，不会把个人数据复制成两份。不要删除旧入口，也不要为了“清理”而删除旧入口里面的文件——那就是新文件夹中的实际文件。

成功后，本次备份和日志会自动删除；若提示“备份暂未清理”，可重新打开工具，点击 **恢复** 重试清理，不需要重新改名。

维护账户可以保留备用。确认原账户和软件都正常后，若准备删除维护账户，请先确认电脑上还有可用的管理员账户，再从 Windows 设置中删除**维护账户**；务必核对名称，别删除自己的原账户。

## 出错了怎么办？

| 看到的提示 | 接下来怎么做 |
| --- | --- |
| 没有找到其他用户 / 这个用户正在使用电脑 | 注销原用户，登录另一个管理员，再打开工具。 |
| 目标用户仍已加载 / 仍有进程 | 重启，只登录维护管理员，不要先登录原用户。 |
| 自动改名被阻止 | 按第 5 步手动改名，再点 **我已改名，继续迁移**。 |
| 已回滚 | 软件已撤回本次记录的改动。查看 **本次详情**，按具体提示处理后重试。手动改过的文件夹会保留新名称，继续迁移前保持原用户注销。 |
| 自动恢复未完成 / 存在尚未恢复的操作 | 按下面的恢复步骤处理，先不要登录原用户。 |
| 迁移已完成，备份暂未清理 | 点击 **恢复**，选择本次记录，点击 **恢复选中操作**，只会清理成功记录，不会撤销已成功的迁移。 |

### 需要恢复时，按这几步

1. 保持原用户注销，在另一个管理员账户中打开工具；如果刚发生断电、强制退出，先重启并只登录这个管理员。
2. 点击 **恢复**，选择与本次操作时间对应的记录。可以先点击 **查看选中记录**核对。
3. 点击 **恢复选中操作**，等处理结束，按结果提示操作。
4. 自动改名流程恢复成功后，原文件夹名称和软件修改的设置会还原。**手动改名流程只恢复软件设置，保留手动改好的文件夹和旧路径入口**；这种情况请继续完成迁移后再登录原用户。

成功后若还想换一个名称，请把它当作一次新的改名操作；“恢复”不提供撤销已经完成且备份已清理的迁移。

如果恢复仍失败，保留 `C:\ProgramData\RenProfile-Py` 中的资料，不要自行删改。点击 **本次详情 → 复制详情**，在[问题反馈](https://github.com/zhaibingye/RenProfile-Py/issues/new/choose)中提供：软件版本、Windows 版本、出错步骤和完整错误文字。详情可能含用户名和路径，公开前可以替换这些个人信息；无需上传整个用户文件夹、注册表文件或恢复数据库。

## 它具体会做什么？

重新读取当前账户信息 → 扫描相关路径设置 → 改名（受阻时手动接续）→ 建立旧路径兼容入口 → 更新相关设置和原 SID 的目录绑定 → 校验 → 清理本次恢复资料。

它不会创建替代原用户的新账户，也不会自动结束其他软件或关闭系统服务。每次开始都会重新扫描；历史记录放在恢复窗口，不会混入本次详情。对无法修改的非关键设置，会保留原值并依靠旧路径入口兼容；关键绑定更新失败时会尝试回滚。
